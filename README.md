# orbital-encylopedia

# 🌌 ORBITAL — A Field Guide to the Solar System

A single-page interactive encyclopedia of the solar system and beyond — built with plain HTML, CSS, and JavaScript. No frameworks, no build step.

**[Cick here ](https://ayushmanxai.github.io/orbital-encylopedia/)**


## What's inside

- **Live orbital diagram** — all 8 planets animate around the Sun at correct *relative* speeds (Mercury fastest, Neptune slowest)
- **Click any planet** to open a field-record panel with real data: diameter, distance, orbital period, day length, moons, and average temperature
- **Deep sky section** — five real Hubble/Webb images of galaxies and nebulae (Andromeda, Whirlpool Galaxy, Pillars of Creation, Orion Nebula, Crab Nebula), each with its own record
- Fully responsive, keyboard-accessible,
